NEON DODGE — a tiny browser game my AI agent built from one prompt, filmed while it worked, and posted on X. Watch the prompt become a playable game in one short clip: the prompt, the agent writing the code, and the finished game running.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

Play the game: open `game/index.html` in a browser — move with the mouse or arrow keys, dodge the meteors, survive as long as you can. Add `?auto=1` to watch it play itself, or `?auto=1&t=14` to jump straight to a mid-game moment.

The video: `video/` in the build workspace (not shipped here) shows the prompt, the agent writing this code, and the game running — ending on make.fun's referral card. The post on X carries the video and this entry's play code.
